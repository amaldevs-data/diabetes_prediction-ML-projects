Diabetes Prediction System
Built a machine learning model to predict diabetes risk with 89% accuracy, enabling early intervention.
Developed a Diabetes Prediction System using Python and machine learning algorithms to classify patients as diabetic or non-diabetic based on clinical data.
Performed data preprocessing including missing value handling, feature scaling, and exploratory data analysis (EDA).
Implemented models such as Logistic Regression, Random Forest, and Support Vector Machine, and evaluated them using accuracy, precision, recall, and ROC-AUC. 
The project demonstrates practical application of data science and predictive analytics in healthcare.
